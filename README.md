# Harbour House hosted preview

This repository contains the static browser assets for the Harbour House website hosted at GitHub Pages. The private development repository remains the source of truth.

The page is marked noindex, but this is a public preview URL. Do not add credentials, private guest information, or server configuration here.

Availability is still sample data. Email delivery is being prepared through Google Apps Script; the enquiry form remains disabled until the Harbour House owner authorizes and deploys the script and its `/exec` URL is added to `enquiry-config.js`. The script sends to the owner and acknowledges the guest without creating a Calendar event. Never put credentials or tokens in this repository.
